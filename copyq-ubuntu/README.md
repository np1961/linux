# CopyQ на Ubuntu 24 (Wayland)

То же, что на Mac (2026-11-25): история последних 9 копий и 9 слотов на правом цифровом блоке.

| Нажатие | Что делает |
|---|---|
| правая 1…9 | показать запись N из истории (1 = самая свежая), 5 с |
| правый 0 | вставить показанную запись |
| держишь правый **+** и жмёшь N | положить выделенное в слот N |
| держишь правый **−** и жмёшь N | вставить слот N |
| просто + или − | печатают плюс/минус как обычно |

Ctrl+C / Ctrl+V работают как обычно. Слоты не попадают в историю и не меняют обычный буфер.

## Установка (в терминале, открытом в этой папке)

```
bash install.sh
bash keyd-add.sh
```

Обе спросят пароль. Каждый шаг печатает `OK` (или `FAIL` и останавливается). `install.sh` в конце печатает сеть CopyQ — должно быть пусто.

## Как устроено
На Wayland CopyQ не может сама ловить клавиши и нажимать Ctrl+C/Ctrl+V, поэтому:
- **keyd** по правой клавише сам запускает `~/.local/bin/cq` (`command(...)`), как на Mac: клавиша сразу зовёт CopyQ, сочетания GNOME не нужны и ни с чем не конфликтуют;
- keyd работает от root, поэтому `cq` запускается от вас: `setpriv --reuid=… --reset-env` (подставляет keyd-add.sh вместо `@CQ@`);
- Ctrl+C / Ctrl+V жмёт тоже keyd (`keyd do C-v`) в той же команде, паузы делает `sleep`: в keyd v2.6 `command` нельзя ставить внутрь `macro(...)`;
- **CopyQ** (запущена через XWayland, иначе не видит буфер) хранит историю и слоты, показывает подсказки.

| Файл | Что |
|---|---|
| install.sh | ставит CopyQ, настройки, автозапуск, скрипты |
| keyd-add.sh | вписывает правые клавиши в /etc/keyd/default.conf (между `# copyq begin` / `# copyq end`), подставляет `@CQ@` |
| keyd-copyq.conf | сами правила keyd |
| js/ | действия CopyQ: preview, paste, mark, put, get + общий common.js; js/cq — запускалка |
| uninstall.sh | откат всего |

## Проверка
- Скопировать «кошка», потом «собака». Правая 2 → подсказка «кошка», правый 0 → вставилось «кошка».
- Выделить «кошка», держать + и нажать 2 → «Слот 2 / сохранено». Скопировать «собака» (Ctrl+C). Держать − и нажать 2 → вставилось «кошка». Ctrl+V → «собака». В истории «кошки» из слота нет.
- Пустой слот или ничего не выделено → «Слот N / красный X».

## Если не работает
- Вставляется старое: паузы малы. В keyd-copyq.conf увеличить `sleep 0.25` (правый 0) / `sleep 0.4` (из слота) / `sleep 0.35` (в слот), потом `bash keyd-add.sh`.
- В терминале вставка не срабатывает: там вставка Ctrl+Shift+V, а keyd жмёт Ctrl+V.
- Ничего не происходит: проверить в терминале `~/.local/bin/cq preview 1`; ошибки команд keyd — `journalctl -u keyd -n 30`.
- В js/ нельзя `\n` и `\/`: `copyq eval` раскрывает обратные слэши.

## Откат
`bash uninstall.sh` — убирает правила keyd, сочетания GNOME, автозапуск и скрипты. Саму CopyQ удаляет отдельно (команда печатается в конце).
